Plugin de WordPress: Proximos Lanzamientos Espaciales

Instalacion
1. Copia la carpeta `wordpress-plugin-proximos-lanzamientos` dentro de `wp-content/plugins/`.
2. Activa el plugin desde el panel de WordPress.
3. Inserta el shortcode `[proximos_lanzamientos]` en cualquier pagina o entrada.

Notas
- El plugin consulta Launch Library 2 desde el navegador del visitante.
- La hora principal se muestra en la zona local del navegador y la UTC aparece entre parentesis.
- Si un lanzamiento trae enlaces publicos, el plugin muestra botones como `Video`, `Web` o `Web oficial`.
